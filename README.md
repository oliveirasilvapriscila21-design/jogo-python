# 🐍 Projetos Iniciais em Python

Este repositório reúne meus primeiros projetos práticos desenvolvidos em Python durante a minha transição de carreira para a área de Tecnologia. O objetivo é aplicar conceitos de lógica de programação, manipulação de arquivos e automação na prática.

---

## 🎮 1. Jogo: Pedra, Papel e Tesoura (Jokenpô)

Um jogo clássico interativo executado direto no terminal, onde o usuário joga contra o computador.

### 🚀 Funcionalidades
- **Entrada do Usuário:** Captura a escolha do jogador através de comandos simples.
- **Inteligência do Computador:** Utiliza a biblioteca `random` para gerar escolhas aleatórias e imprevisíveis para a máquina.
- **Lógica de Condicionais:** Avalia as regras do jogo (Pedra ganha de Tesoura, Tesoura ganha de Papel, Papel ganha de Pedra) e determina o vencedor ou empate.

### 🛠️ Conceitos Praticados
- Estruturas condicionais (`if`, `elif`, `else`).
- Importação e uso de módulos nativos (`random`).
- Loops de repetição e interação com o usuário via terminal.

---

## 📂 2. Organizador Automático de Pastas

Um script focado em automação para resolver a bagunça de arquivos soltos no computador.

### 🚀 Funcionalidades
- **Organização Inteligente:** Varre uma pasta específica, identifica as extensões dos arquivos e os move para subpastas estruturadas (Imagens, Documentos, Vídeos, etc.).
- **Tratamento de Erros:** Verifica a existência de diretórios e gerencia caminhos do Windows de forma segura.

### 🛠️ Conceitos Praticados
- Manipulação de arquivos e caminhos do sistema operacional (bibliotecas `os` e `shutil`).
- Tratamento de exceções e automação de rotinas.

---

## 💻 Como Executar os Projetos

1. Certifique-se de ter o Python 3 instalado no seu computador.
2. Clone este repositório ou baixe os arquivos.
3. Abra o terminal na pasta do projeto e execute o script desejado:
   - Para o jogo: `python jokenpo.py` (ou o nome exato do seu arquivo do jogo)
   - Para o organizador: `python organizador.py`# jogo-python
